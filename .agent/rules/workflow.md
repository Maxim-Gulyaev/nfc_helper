# Rules: Workflow

Процесс работы над репозиторием NFC Helper.

## Обязательный минимум перед завершением любой задачи

1. `./gradlew :app:assembleDebug` — сборка зелёная.
2. `./gradlew :app:testDebugUnitTest` — тесты зелёные.
3. Если задача затрагивала UI-строки/ресурсы — проверить, что ничего не захардкожено
   (см. [code-style.md](code-style.md)).

## Git

- Ветки от `main`; осмысленные имена (`feature/read-tab-ui`, `fix/nfc-adapter-null`).
- Коммиты: короткая тема в императиве на английском
  (`Add read tab placeholder`, `Fix settings back navigation`).
- Не коммитить артефакты сборки: `.gradle/`, `build/`, `.kotlin/`, локальные конфиги —
  они уже в `.gitignore`.
- Не переписывать историю `main` (rebase/force-push) без явной просьбы пользователя.

## Границы изменений

- Минимальный диф: только то, что относится к задаче.
- Нашёл несвязанную проблему → сообщи пользователю отдельно, не исправляй молча.
- Публичные контракты (сигнатуры экранов, `Screen`, структура `UiState`) менять только
  по задаче или после согласования.
- Новые зависимости в `app/build.gradle.kts` — только после согласования с пользователем.

## Коммуникация с пользователем

- Язык общения — русский; код, комментарии, коммиты — английский.
- Прежде чем писать код по неоднозначной задаче — уточни требования.
- По завершении: краткий отчёт (что сделано, что проверено) + предложение следующих шагов,
  если есть.
